保留原工具的森林深色、铜金边框及山峦背景。全站导航固定为“今日日常 / 12天循环 / 碎层异变”，三页共享布局及吸顶行为；窄屏采用品牌/语言和导航两行，给滚动定位预留顶部空间。

团队悬赏保留四张目标卡片、日期、复制及 PNG 分享。轮换表在手机上使用卡片，桌面使用表格。
首页按“十人本悬赏”和“碎层”组织二级标题。碎层内按 CM、T4 日常、推荐组织三级标题，关卡名为四级标题；CM 使用通栏紧凑列表，宽屏的 T4 与推荐并排，窄屏纵向排列。所有名称和异变自然换行，不折叠隐藏结果。推荐展示任务指定层数，CM/T4 重合时双向标记。日期、复制和截图作用于两个板块；分享图动态计算全部行高，不受浏览器窗口或滚动位置影响。

首页的“轮换第 n / 12 天”归属十人本，置于该板块标题旁，随所选日期更新。首页刷新倒计时为 30px（手机 26px）的铜金描边数字，刷新规则独立展示；碎层页倒计时同步强调为 24px，数字固定宽度并保留 timer 语义。

日常分享 PNG 的顶部副标题仅显示所选 UTC 日期，轮换进度以铜金徽标放在“十人本悬赏”标题旁。按用户要求，分享图不展示倒计时及生成时间面板。图片继续完整包含十人本、CM、T4 日常和推荐碎层，页脚保留刷新规则及来源；中英文内容动态测量后绘制。

碎层页面按任务排列：日期 → CM/日常/阶级 → 搜索及异变筛选 → 结果 → 日期反查 → 资料来源。筛选控件有可见标签，结果支持键盘访问；异变标签换行，不裁切名称。

碎层采用紧凑行式布局：桌面每行一个关卡，左侧集中显示层数、名称、抗性和标识，右侧并排展示异变；手机自动改为上下两行，长名称自然换行。移除该页的大幅背景横幅，日期和刷新倒计时压缩到标题下方，日期控件与资料版本并排；模式切换和搜索筛选在宽屏合并为一排。反查区的说明、选择控件和日期结果采用紧凑网格。操作按钮保持至少 44px 高度。

2026-10-25 同尺寸对比：1280×900 中文窗口中，7 个 CM 的结果区高度由约 821px 降至 426px，同屏完整显示由 3 个增加到 7 个。此次仅调整碎层布局和短文案，未修改业务算法与资料。

日期反查独立为 `FractalDateSearch.vue`，仅查询挑战模式，按“天数／CM 关卡 → 包含／排除 → 匹配规则／抗性 → 结果”排列。CM 支持多选，留空代表全部；候选仅来自 CM 身份及当前最高层数，并按各日期判断是否已开放。移除通用模式范围和星期筛选。条件使用带标签的原生控件，已选值用可键盘移除的按钮标签展示，包含与排除不能冲突；桌面三列／两列，手机单列。结果立即更新，按日期由近到远分组，显示符合数／整组数及完整异变；包含条件高亮。每页最多 5 个日期，随关卡数减少日期数以控制行数，不拆散同一天；每页完整渲染以避免延迟排版引起翻页位置跳动。复制使用完整结果与查询条件，不受当前页限制。

反查使用原生 details/summary，默认收起，仅显示标题和“展开”。首次展开后才挂载筛选表单并执行查询；收起时关闭计算但保留筛选，再展开按当前日期恢复。折叠标题保留二级标题和原生键盘／展开状态语义。

碎层名称和悬赏任务名优先使用已核对的官方 API 中文；异变和 Boss 全名保留独立来源，未经确认的新名称回退英文。数据版本和预测性质在资料说明中明确展示。图片分享通过原生 dialog 预览，生成后独立点击才打开系统分享；取消分享仍可保存。
